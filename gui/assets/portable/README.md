# Ícono de pokeLDN Portable

`icon.png`: maestro PNG, 1254 × 1254, canal alpha. Generado el 2026-11-13 mediante la herramienta integrada **imagegen** (sin CLI/API externa). Inspeccionado visualmente; tamaño y alpha comprobados con `sips`.

Destino: ícono del acceso Linux y fuente para futuro bundle macOS. No reemplaza `gui/assets/icon.png`, `icon.ico` ni `gui/AppIcon.icon`; tampoco modifica el cliente Flet compartido. El Dock nativo conserva su ícono actual hasta integrar la identidad en el empaquetado.

## Prompt utilizado

> Create a finished premium desktop application icon, square 1024x1024 transparent canvas, for a portable Pokémon workshop inspired by a Pokédex. A single bold compact red handheld Pokédex device viewed straight on, softly rounded corners, rich coral red enamel body, small luminous cyan circular sensor upper left, cream inset screen with one large iconic red-and-white Poké Ball at center, subtle charcoal directional cross on lower left and two small buttons lower right. Tasteful gently dimensional macOS app-icon finish, crisp clean silhouette, limited detail readable at 32px, balanced optical spacing, soft restrained highlights, no text, no lettering, no scene, no extra objects, no background tile outside device, generous transparent margin. Colors match app coral #D93843, cream #F3F1EA, charcoal #243139, cyan #00A9BA. Deliver one icon only.

La herramienta devolvió 1254 × 1254; se conserva el original sin redimensionarlo. La legibilidad a tamaños pequeños y las variantes `.icns` deben comprobarse al integrar el paquete.
